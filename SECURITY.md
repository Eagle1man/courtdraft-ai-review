# Безопасность CourtDraft AI

## Обработка данных

CourtDraft AI работает **только локально**. Материалы судебных дел являются
персональными данными и не должны покидать машину.

## Что система НЕ делает

- не обращается к облачным LLM (OpenAI, Anthropic и т. п.);
- не обращается к облачным embedding API;
- не отправляет судебные документы во внешние сервисы;
- не публикует и не утверждает судебные акты.

Проверяется конфигурацией: OLLAMA_BASE_URL указывает на локальный адрес,
CORS разрешает только localhost.

## Известные ограничения MVP

1. **Обезличивание PII основано на регулярных выражениях.** Это не защита
   уровня production. Перед использованием на реальных данных нужен
   специализированный подход (словари, контекст, ручная проверка).
2. **Аутентификация и авторизация не реализованы.** MVP рассчитан на запуск
   на локальной машине одного пользователя. Выставление в сеть недопустимо
   без реализации контроля доступа.
3. **Шифрование данных на диске не реализовано.** Материалы дел хранятся
   открыто в каталоге data/cases/.
4. **Журналирование аудита не реализовано** (Фаза 3+). Отсутствует история
   действий с документами.

## Рекомендации перед применением на реальных делах

- развернуть в защищённом контуре;
- реализовать RBAC и аудит;
- добавить шифрование хранилища;
- провести оценку воздействия на защиту данных;
- проверить качество обезличивания на реальных выборках.
