# Участие в разработке

## Обязательно к прочтению

1. [AGENTS.md](AGENTS.md) — правила проекта, юридические ограничения,
   режимы MOCK/REAL, критерии готовности.
2. [docs/architecture.md](docs/architecture.md) — архитектура и текущее
   состояние фаз.

## Окружение

`powershell
.\scripts\install.ps1
.\scripts\start.ps1
.\scripts\health.ps1
`

Разработка идёт на машине **8 GB RAM без GPU**. Реальная модель не нужна и
не должна запускаться: используйте MOCK-режим.

## Перед отправкой изменений

`powershell
cd backend
.venv\Scripts\python.exe -m pytest
.venv\Scripts\ruff.exe check app tests
.venv\Scripts\mypy.exe app
`

Все три команды обязаны завершаться успешно.

## Правила

- Одна фаза — один набор изменений.
- Новая бизнес-логика — с тестами.
- Миграции БД обратимы (Alembic downgrade).
- Комментарии объясняют «почему», не «что».
- Код и имена — по-английски, тексты интерфейса — по-русски.
- Не трогайте чужие файлы и не удаляйте существующий код.

## Юридические ограничения

Особенно важно для этого проекта: система готовит **проект** акта, а не
принимает решение. Запрещено выдумывать факты, доказательства, нормы права
и судебную практику. Нарушение этих правил — не стилистическая ошибка,
а дефект продукта.
