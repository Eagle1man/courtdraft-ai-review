## 1. MissingGreenlet (P0) — причина и фикс

**Причина.** `TimestampMixin.updated_at` объявлен с `onupdate=func.now()`
(`backend/app/models/entities.py`, строки 156–164): flush делает UPDATE, после
чего атрибут `updated_at` помечен протухшим. Последующее чтение
`draft.updated_at` в `_draft_out`
(`backend/app/api/routes/drafts.py`, строка 187) шло вне greenlet →
`sqlalchemy.exc.MissingGreenlet` → 500.

Факт из лога старого процесса (до фикса):
`SELECT drafts.updated_at FROM drafts WHERE drafts.id = ?` с параметром
`cf5f3e8c-5794-44cc-be58-c345a66da9d0` → исключение →
`POST /api/cases/0cd82051…/draft?wait=true` → **500 Internal Server Error**.

**Фикс** — явный `await session.refresh(draft)` в двух местах
(`backend/app/api/routes/drafts.py`):
- ветка `wait=true` перед вызовом `_draft_out(draft, version, report)`;
- `PATCH /drafts/{id}/status` после чтения relation `versions`/`verifications`.

Эталон — уже работающий `update_case`. Альтернатива (`eager_defaults`)
отклонена: шире по охвату и зависит от диалекта.

**Проверка в живом приложении:** тот же `POST …/draft?wait=true` →
**202 Accepted** (лог uvicorn), до фикса — 500.
